## 一、能力演示类（3 个）

### 案例 1｜全国统一考试语文试卷

| 项目 | 内容 |
|------|------|
| 方式 | 文生图 T2I |
| 推荐版本 | Pro（整版 A4 密集排版） |
| 核心能力 | 内容丰实--一整页试卷从密级标识到页脚全部文字精确渲染 |

**提示词结构解析**：

1. **开篇定调**：「这是一张竖版白底黑字的中文考试试卷扫描页，整体呈现 A4 纸张的 flat, scan-style 规整排版」--一句话锁定画幅方向（竖版）、色调（白底黑字）、风格（扫描级排版）、纸张规格（A4）。
2. **空间动线**：严格按页面物理布局从上到下--顶部密级文字 → 主标题 → 科目标题 → 考试说明 → 注意事项（三条编号） → 第一大题标题 → 小节标题 → 引导语 → 材料正文 → 柱状图 → 数据来源 → 页脚。
3. **文字逐字写入**：每段需要渲染的文字都用引号标出并写明位置，如「页面顶部左侧印有小号密级文字"绝密★启用前"」「其正下方以更大字号、加粗字体显示科目标题"语文（甲卷）"」。
4. **细节要素**：字体（黑色宋体、加粗）、墨迹（锐利易读）、页面边缘（纯白宽边）。

**关键技巧**：
- 将页面当作物理空间逐区域扫描式描述，每段文字标明在页面中的位置（顶部左侧/上方居中/下方居中等）。
- 文字渲染须指定字号层级（大号主标题 → 更大字号科目标题 → 加粗小标题 → 正文），模型据此排出版面层级。
- 柱状图等非文字元素也要描述灰度、标签、数据来源。

### 案例 2｜刺绣微距

| 项目 | 内容 |
|------|------|
| 方式 | 文生图 T2I |
| 推荐版本 | Pro（织物纹理、绣线光泽需极致细节） |
| 核心能力 | 细节真实--放大后刺绣质感依然成立 |

**提示词结构解析**：

1. **开篇定调**：「画面是一张横向构图的写实摄影特写」--锁定构图方向与摄影类型。
2. **空间动线**：背景整体氛围 → 左侧手 → 右下方手 → 绣针 → 画面中央布面与绣绷 → 布面图案（小鸟） → 植物枝条 → 光照总结。
3. **细节五要素**：
   - 色彩：米白与浅灰背景、浅绿色绣线、银灰色针体、浅米色亚麻布。
   - 材质：亚麻布细密交织纹理、木质绣绷浅木色光滑、丝线渐变纹理。
   - 光影：自然光柔和漫射、阴影轻浅、左上与边缘轻微虚化。
   - 质感：手指纹理清晰、指甲自然短圆、绣线形成松弛弧形线圈。
4. **景深处理**：明确「景深较浅」「左上与边缘区域轻微虚化」，营造近摄特写感。

**关键技巧**：
- 微距摄影须描写皮肤纹理（指节纹理、指甲形状）、材质纤维（织物交织纹理、绣线渐变）等肉眼需放大才看到的细节。
- 两只手分别描述位置与动作（左手按住线迹、右手捏线牵引），形成操作瞬间的动态定格。
- 动植物刺绣图案也要描写用色层次（米白/浅褐/橄榄绿/灰褐色丝线表现羽毛层次）。

### 案例 3｜手写数学复习笔记

| 项目 | 内容 |
|------|------|
| 方式 | 文生图 T2I |
| 推荐版本 | Pro（手写体、数学公式、几何图混合排版） |
| 核心能力 | 内容丰实+细节真实--三色手写批注、数学符号、手绘几何图 |

**提示词结构解析**：

1. **开篇定调**：「这是一张白底纸面的手写数学复习笔记扫描图」--锁定扫描风格与手写笔记类型。
2. **空间动线**：页面分四大区块--顶部标题区 → 左上主图（正多边形二面体群图解） → 中右批注与提示框 → 下中第二部分 → 下左第三部分 → 下右第四部分 → 底部右总结框。每个区块写明在页面中的位置。
3. **三色系统**：明确区分黑色签字笔（正文推导）、蓝色圆珠笔（公式框、提示、标注）、红色标注（核心结论、箭头、总结框），形成层次分明的批注体系。
4. **数学内容**：所有公式、符号（D_n、⟨r_n⟩、V_1、b_{{n+1}}=b_n+1）逐字写入，几何图顶点标签写明位置。
5. **手绘元素**：描述手绘矩形框、箭头方向、波浪线、双下划线等标注样式。

**关键技巧**：
- 数学笔记须把公式逐字写入提示词，并标明颜色（黑/蓝/红）与书写工具。
- 几何图须描述图形形状、对称线段、顶点标签位置、辅助线颜色方向。
- 多区块笔记须按页面位置逐块描述，每块写明标题、正文、公式、手绘元素的颜色与内容。

### 案例 4｜3 张商品图合成家装实景（I2I）

| 项目 | 内容 |
|------|------|
| 方式 | 图生图 I2I（3 张白底商品参考图） |
| 推荐版本 | 标准版（日常电商场景合成）；Pro（极致材质还原） |
| 核心能力 | 多图合成--提取多张商品图主体，自动搭配软装与光影 |

**提示词结构解析**：

1. **目标声明**：「根据所有商品图生成真实家装效果图」--一句话说明编辑目标。
2. **过滤指令**：「仅提取家具主体，忽略价格、促销文字、品牌标识等干扰信息」--告诉模型忽略白底商品图中的非主体元素。
3. **完整性约束**：「必须使用全部输入商品，不得遗漏」--防止漏用参考图。
4. **保留与生成**：「保留家具外观、颜色和材质，自动设计协调室内背景并合理布置」--明确保留什么（家具本体）、自动生成什么（室内背景）。
5. **补充建议**：「可适当补充地毯、窗帘、挂画、绿植、摆件、氛围灯等协调软装，减少空墙和空地，增强空间层次与生活感」--给模型留出创意空间但限定品类。
6. **质量约束**：「保证比例、透视、光影自然；画面需完整充满整张输出图片，不留白边或边框」。
7. **负面约束**：「不要生成电商促销主图、文字或价格信息」--收尾约束。

**关键技巧**：
- I2I 多图合成的提示词重心在「编辑规则」而非「画面描写」：先声明提取什么、忽略什么、保留什么、自动生成什么。
- 用「必须」「不得」等强约束词确保全部参考图被使用。
- 给出软装补充清单（地毯/窗帘/挂画/绿植/摆件/氛围灯），模型据此自动填充空间。

### 案例 5｜东方古典角色设定稿（多视角一致性）

| 项目 | 内容 |
|------|------|
| 方式 | 文生图 T2I |
| 推荐版本 | Pro（多视角一致性、服饰细节） |
| 核心能力 | 同一人物多视角展示--半身特写+正/侧/背全身，五官服饰完全一致 |

**提示词结构解析**：

1. **开篇定调**：「真实摄影, 电影级RAW原片，专业古风角色设定稿，同一人物多视角展示」--锁定风格、类型、核心要求（多视角一致性）。
2. **空间布局**：「画面左侧为人物半身特写，右侧依次排列正面全身、侧面全身、背面全身三视图」--明确画面分区。
3. **环境**：「深灰色哑光质感背景，右侧有柔和暖调侧光光束，影棚高级氛围感」。
4. **人物描写（极详细）**：从头部到脚部逐层描写--发型、头饰、面部、服饰、材质，每个部位写到材质级别（缎面、暗纹提花、垂坠感、褶皱）。
5. **光影**：「影棚级柔和侧光，明暗过渡细腻有层次，人物光影统一」。

**关键技巧**：
- 多视角一致性靠对单个人物的极详细描写实现--把每个人的发型、头饰、面部、服饰、材质逐层写透，模型据此在各视角保持一致。
- 角色设定稿须明确画面分区（左侧特写 + 右侧三视图），让模型知道布局结构。
- 服饰描写要写到材质级别（缎面、暗纹提花、垂坠感、褶皱），而非仅写颜色。

- 主视觉人物须极详细描写，作为图鉴的视觉焦点。
- 色板、纹样、流程图等辅助模块须写明色块名称与寓意、纹样名称与寓意、流程步骤编号与说明。

| 推荐版本 | Pro（超宽横版，多分区信息图） |
| 核心能力 | 知识厚实--中文指令指定渲染英文内容，历史教学图文 |

**提示词结构解析**：

1. **开篇定调**：「超宽横版英文历史教育信息图」--锁定画幅（超宽横版约 3:1）、类型、内容语言（英文）。
2. **空间动线**：顶部插画+标题+摘要 → 第一行左右栏（OVERVIEW + MAP） → 中部时间线（五列） → 下方左右栏（CAUSES + IMPACT） → 底部 Historical Significance。
3. **双语模式**：提示词用中文描述结构与分区，渲染的文字内容用英文写入。
4. **画幅与风格约束**：「横版约 3:1，信息图印刷品质，清晰网格，栏目对齐，英文拼写与年份必须准确」。
5. **负面约束**：「避免文本乱码、城市位置严重错误、地图轮廓畸形、栏目重叠、字体大小无层级、现代军装、霓虹色、3D 卡通、水印」。

**关键技巧**：
- 中文指令+英文内容模式：用中文描述版面结构与分区逻辑，需要渲染的文字用英文逐字写入。
- 超宽横版须显式声明比例（「横版约 3:1」），并在约束中要求「栏目对齐」「字体大小有层级」。
- 历史类信息图须写明年份、地名、人名的英文拼写，并在负面约束中强调「避免文本乱码」「城市位置严重错误」。

### 案例 11｜意式街头暖阳人像

| 项目 | 内容 |
|------|------|
| 方式 | 文生图 T2I |
| 推荐版本 | Pro（商业人像，逆光轮廓光，胶片质感） |
| 核心能力 | 细节真实--商业人像摄影，多层背景叙事，规避塑料感 |

**提示词结构解析**：

1. **开篇定调**：「画面是一张竖幅户外人像摄影，整体从上到下呈现温暖的午后街景氛围」。
2. **空间动线**（从上到下）：顶部藤蔓花叶 → 深蓝色招牌 → 报刊亭玻璃橱窗 → 右上方逆光区域 → 画面中部偏右人物半身像 → 下部花束 → 右侧街道远景 → 整体胶片感处理。
3. **人物描写**：发型（长而浓密的黑色波浪卷发、金色轮廓光）、肤色（白皙）、脸型（鹅蛋形）、五官（眉形细致、眼睛明亮、眼妆清透）、唇色（珊瑚红色）、表情（笑容露齿）、配饰（小巧耳饰）、服装（黑色细肩带露背连衣裙、面料深黑）。
4. **光影氛围**：逆光轮廓光、浅景深、暖色胶片感、细腻颗粒、柔和对比。
5. **背景叙事**：藤蔓/招牌/橱窗/街道/交通标志等背景元素逐层描写，形成有故事感的氛围。

**关键技巧**：
- 商业人像须从上到下逐层描写背景元素，每层写明色彩、质感、虚化程度，形成有故事感的氛围。
- 人物须极详细描写发型/肤色/脸型/五官/唇色/表情/配饰/服装/材质，并写明光影效果（逆光轮廓光、金色发丝光）。
- 结尾写明整体胶片感处理（颗粒、对比、边缘光），定调照片质感。

### 案例 12｜盛夏草帽光影薄荷水

| 项目 | 内容 |
|------|------|
| 方式 | 文生图 T2I |
| 推荐版本 | Pro（光影斑驳人像，质感真实） |
| 核心能力 | 细节真实--草帽编织孔洞的网格状投影、透明玻璃杯与薄荷水质感 |

**提示词结构解析**：

1. **开篇定调**：「明亮盛夏户外写实人像，东亚年轻女性正面近景」。
2. **人物与道具**：黑色微卷长发、宽檐编织草帽（边缘有毛边）、白底浅蓝碎花棉质连衣裙、透明方形玻璃杯（绿色薄荷水+冰块+薄荷叶）。
3. **核心光影**：「正午阳光穿过草帽编织孔洞，在额头、眼睛、鼻梁、脸颊和嘴唇投下精细的网格状斑驳光影」--精确描写光影的成因与落点。
4. **背景**：茂盛绿叶和明亮圆形散景。
5. **画幅与摄影参数**：「竖版 3:4，85mm，f/2，明亮高调曝光，清爽绿色与天蓝色配色，真实商业人像摄影，微弱胶片颗粒，细节锐利但肤质自然」。
6. **负面约束**：「避免草帽纹理混乱、阴影方向错误、杯口或手指畸变、饮料浑浊、过曝丢失五官、假睫毛过重、文字与标识」。

**关键技巧**：
- 人像摄影可在提示词末尾附专业摄影参数（画幅比例、焦段、光圈、曝光风格、胶片颗粒），模型据此调整成像风格。
- 光影效果须写明成因与落点（如「阳光穿过草帽编织孔洞 → 投在额头/眼睛/鼻梁/脸颊/嘴唇」），而非仅写「有光影」。
- 负面约束针对场景易错点逐条列出（草帽纹理混乱/阴影方向错误/杯口畸变/饮料浑浊/过曝/假睫毛过重），有效防翻车。
