> 本文件融合官方最佳实践手册（`Qwen-Image-3.0官方最佳实践案例与完整提示词手册.md`）的核心方法论与实战经验。

## 一、模型能力概览（官方「三实」）

Qwen-Image-3.0 的核心追求从「好看」转向「好用」--生成的图要能成为可直接交付的成品。官方用三个「实」概括：

| 能力 | 说明 | 关键指标 |
|------|------|----------|
| **内容丰实** | 装得下一整页：试卷、报纸、图鉴、信息图一次生成 | 指令长度提升至 4.5K token |
| **细节真实** | 经得起放大：纹理质感逼近真实材质 | 10px 小字清晰可辨，毛孔发丝纤毫毕现 |
| **知识厚实** | 什么都懂：跨语言、跨领域 | 覆盖 12 国语言、100+ 艺术风格与多种 UI 界面 |

- Pro 版在「图中图密集信息排版」「微表情/毛孔/发丝真实细节」「外部知识全纳入」三方面进一步强化。
- 标准版在指令理解、文字渲染、批量产出上已足够日常创作，且 1K/2K 同价更省。

## 二、官方使用技巧（3 条）

1. **指令可以「长」**：4.5K token 是留给复杂版面的--想要九宫格、整版报纸、完整图鉴，就把每个区域、每段文字、每个相对位置都描述清楚，模型接得住。不要怕长，关键是结构化。
2. **小字要「点名」**：想要试卷、笔记、论文里的精确文字，直接把要渲染的正文写进指令，模型会照着排。用引号标出文字内容，并指定字体、字号、颜色、位置。
3. **风格要「说全」**：100+ 艺术风格 + 12 国语言，越具体越准--摄影风写光线镜头氛围（焦段、光圈、曝光、胶片颗粒），插画风写材质配色笔触（水彩/油画/扁平矢量/手绘）。

## 三、提示词结构范式（从 12 个官方案例归纳）

构建提示词时，按以下 6 步骨架组织内容。并非每步都必须，但复杂场景应尽量覆盖：

### 第 1 步：开篇定调

一句话说明画面类型、画幅方向、整体风格与氛围。

- 示例：「这是一张竖版白底黑字的中文考试试卷扫描页，整体呈现 A4 纸张的 flat, scan-style 规整排版」
- 示例：「画面是一张竖幅户外人像摄影，整体从上到下呈现温暖的午后街景氛围」
- 要点：锁定画幅方向（竖版/横版/方形/超宽横版）、色调基调、风格类型、核心主题。

### 第 2 步：空间动线

严格按空间顺序（从上到下、从左到右、从主体到背景）逐区域描述，并写明各元素的相对位置关系。

- 文档排版类：按页面物理布局从上到下逐区扫描（顶部 -> 标题区 -> 正文区 -> 图表区 -> 页脚）。
- 人像摄影类：从上到下逐层描写背景元素 -> 主体人物 -> 前景道具 -> 远景。
- 信息图类：按视觉权重从主到次（最大视觉元素 -> 辅助模块 -> 图例/标注）。
- 要点：每个元素都要写明在画面中的位置（顶部左侧/上方居中/右下角/画面中部偏右等）。

### 第 3 步：文字逐字写入

所有需要渲染的文字--标题、正文、标注、价格、页脚--用引号逐字写进提示词，一字不漏。

- 示例：「页面上方居中位置排列着大号主标题"2027 年普通高等学校招生全国统一考试"」
- 示例：「菜名与价格："潮州卤水拼盘"、"¥68"」
- 要点：指定字体风格（宋体/书法/哥特体/手写体）、字号层级（大号/小号/加粗）、颜色、位置。
- 跨语言：需要渲染英文/韩文/日文等内容时，直接用目标语言写入文字内容（参见案例 9、10）。

### 第 4 步：细节五要素

| 要素 | 写法 | 示例 |
|------|------|------|
| **色彩** | 给具体色名而非笼统描述 | 「珊瑚红色」「赭红、青蓝、米黄多色拼接」「暖灰与金黄色调」 |
| **材质** | 给质感词 | 「高级缎面材质，垂坠感强」「亚麻布细密交织纹理」「宣纸质感」 |
| **光影** | 给方向与软硬 | 「逆光轮廓光」「正午阳光穿过草帽编织孔洞投下网格状斑驳光影」「柔和漫射光」 |
| **字体** | 给风格 | 「黑色宋体风格印刷，墨迹锐利」「毛笔书法，笔触粗重、飞白明显」 |
| **构图** | 给层次 | 「浅景深效果」「人物位于视觉焦点」「画面分区：左侧特写+右侧三视图」 |

### 第 5 步：收尾约束

部分案例以「避免……」列出负面约束，可有效防翻车。

- 通用负面：乱码、错位、畸变、过曝、水印。
- 场景特定负面（举例）：
  - 人像：「避免假睫毛过重、塑料感、手指畸变」
  - 信息图：「避免文本乱码、栏目重叠、字体大小无层级」
  - 地图：「避免城市位置严重错误、地图轮廓畸形」
- 也可用 `--negative-prompt` 参数传入反向提示词。

### 第 6 步：画幅与摄影参数

写实/人像类可附画幅比例、镜头焦段、光圈等参数，模型据此调整成像风格。

- 示例：「竖版 3:4，85mm，f/2，明亮高调曝光，清爽绿色与天蓝色配色，真实商业人像摄影，微弱胶片颗粒，细节锐利但肤质自然」
- 超宽横版信息图：「横版约 3:1，信息图印刷品质，清晰网格，栏目对齐」
- 要点：摄影参数放在提示词末尾作为风格定调，不与画面描写混在一起。

## 四、文生图（T2I）要点

1. **从上到下/从左到右描述画面构图**，明确各区域内容与位置关系。
2. **主体**写清：人物（年龄/性别/发型/发色/肤色/服装/姿态/表情）、物件、动物等。
3. **关键细节**：色彩、材质、光影方向、景深、文字内容（用引号标出并指定字体/字号/颜色/位置）。
4. **风格氛围**：摄影/插画/3D/水彩等；胶片感/颗粒/对比度；色调（暖色/冷色/大地色）。
5. **约束**：不要出现的内容可用 negative_prompt 参数，或在正向描述中强调"仅含""无多余"。
6. **摄影类附参数**：画幅比例、焦段、光圈、曝光风格、胶片颗粒（参见案例 11、12）。

## 五、图生图/图像编辑（I2I）要点

1. **先声明保留什么**：明确"完美保留输入图片中人物的面部特征与发型"等。
2. **再说明改什么**：换装/换场景/换姿态/换背景，写清新旧对比。
3. **补充新场景细节**：如编辑后的人在新环境中的姿态、道具、光线、构图。
4. 参考图 1-3 张，content 中图片在前、文本在后（文本有且仅有一个）。
5. 编辑迭代时重申"保持 X 不变"，防止漂移。
6. **多图合成**（参见案例 4）：重心在编辑规则而非画面描写--声明提取什么、忽略什么、保留什么、自动生成什么，用「必须」「不得」等强约束词确保完整使用参考图。

## 六、常见问题与对策

| 场景 | 常见问题 | 对策 |
|------|----------|------|
| 图中文字 | 多字/漏字/乱码 | 引号标出文字内容，指定字体/字号/颜色/位置，要求逐字渲染；长文案拆短 |
| 手部/肢体 | 多指、关节反、多肢 | 减少手部特写或明确"五指完整、姿态自然"；出错单点重画 |
| 指定人数 | 漏人/凭空多人 | 明确"恰好 N 人"并写明站位 |
| 风格迁移 | 主体变形 | "保持构图、主体、布局不变，仅改变风格" |
| 尺寸方向 | 比例不符 | 显式 `--size 宽*高`（如 `1920*1080` 横幅、`1080*1920` 竖幅） |
| 编辑漂移 | 多次编辑后偏离原意 | 每次重申不变约束；必要时回到原图重新编辑 |
| 提示词过长 | 丢失细节 | 控制在 4.5K token 内，结构化、抓重点，优先保留主体与构图 |
| I2I 身份保真 | 人物不像 | 文字锚定辨识特征（发型/发色/脸型/肤色/服装）；以原图为唯一参考的图生图保真度最高 |
| 密集排版 | 栏目重叠/字号无层级 | 声明"清晰网格、栏目对齐、字体大小有层级"；负面约束加"避免栏目重叠" |
| 光影方向 | 阴影方向错误 | 写明光源方向与阴影落点（如"阳光从右上方照入"），负面约束加"避免阴影方向错误" |
| 多视角一致性 | 不同视角人物不一致 | 对单人极详细描写（发型/头饰/面部/服饰/材质逐层写透），明确画面分区 |

## 七、尺寸与档位

- 格式 `宽*高`，用星号 `*` 分隔（如 `1024*1024`），**不是** `x`。
- 像素面积 512*512 ~ 2048*2048，宽高比 1:8 ~ 8:1。
- 不指定 `--size` 时模型自动推荐分辨率。
- 档位（影响计费）：面积 <= 2,250,000（约 1500*1500）为 1K 档，超过为 2K 档。
  - 标准版 1K/2K 同价（0.18 元/张）；Pro 版 2K 翻倍（0.50 元/张）。
  - 需 2K 高清且用 Pro 时注意成本翻倍；仅需高清选标准版更省。

## 八、prompt_extend_mode 选择

| 模式 | 适用 | 说明 |
|------|------|------|
| `direct`（默认） | T2I + I2I | 直接提示词增强（DPE），大多数场景适用 |
| `agent` | 仅 T2I | 智能体提示词增强（APE），更精细改写；I2I 传此值会 400 报错 |

- `prompt_extend` 默认开启，对简短描述提升明显；写出详细结构化长提示词后仍建议保持开启。
- 已写出完整长提示词时，可考虑 `--no-prompt-extend` 关闭改写，防止模型自行增删细节。

## 九、迭代建议

- 每次只改一处，新提示词重申不变约束。
- 效果不理想优先调"风格氛围/构图/光线"，再调细节。
- 用 `--seed` 固定种子可复现并微调。
- 出多张候选用 `--n 2~4`，从中挑选。
- 密集排版/信息图类若首次效果不佳，检查是否遗漏了某区域的文字或位置描述，补全后重试。
