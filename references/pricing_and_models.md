# Qwen-Image-3.0 模型与定价

## 模型概览

| 项目 | 标准版 | Pro 版 |
|------|--------|--------|
| 模型 Code | `qwen-image-3.0` | `qwen-image-3.0-pro` |
| 定位 | 质量-速度平衡，日常创作顺手省心 | 内容丰实、细节真实、知识厚实 |
| 输入上限 | 4.5K token | 4.5K token |
| 文字渲染 | 10px 小字、12 国语言、20+ 字体 | 同标准版 |
| 界面仿真 | 主流网页/游戏/直播 | 同标准版 |
| 核心差异 | 指令理解清晰，复杂图文一次生成 | 支持**图中图密集信息排版**；微表情/毛孔/发丝细节逼近真实摄影；外部知识全纳入 |

## 价格对比（元/张）

| 计费项 | 标准版 | Pro 版 | 价差 |
|--------|--------|--------|------|
| 1K 图片输入 | 0.02 | 0.02 | - |
| 2K 图片输入 | 0.02 | 0.02 | - |
| 1K 图片生成 | **0.18** | **0.25** | Pro 贵 39% |
| 2K 图片生成 | **0.18** | **0.50** | Pro 贵 178% |

- 输入价格两版本一致，均 0.02 元/张。
- 标准版 1K/2K 生成同价（0.18）；Pro 版 2K 生成翻倍（0.50）。
- 档位由输出像素面积决定：<=2,250,000 为 1K 档，>2,250,000 为 2K 档。

## 费用计算

```
输入费用 = 输入图片数 x 0.02 元
输出费用 = 输出图片数 x 单价（按版本+档位查上表）
合计 = 输入费用 + 输出费用
```

文生图（T2I）无输入图片，输入费用为 0；图生图（I2I）按实际参考图数计输入费用。

## 选型建议

| 场景 | 推荐版本 | 理由 |
|------|----------|------|
| 日常海报、插画、社交媒体配图 | **标准版** | 成本低，质量足够 |
| 网页/APP 界面原型、UI 设计 | **标准版** | 批量生成，性价比最优 |
| 报纸版面、试卷、分镜脚本 | **Pro 版** | 图中图密集排版，标准版难以胜任 |
| 菜单、信息图表、复杂文档 | **Pro 版** | 信息密度高，需 Pro 保真 |
| 人像摄影、产品特写、细节还原 | **Pro 版** | 微表情、毛孔、发丝等细节更真实 |
| 高分辨率 (2K) 输出需求 | **标准版** | 标准版 2K 同价，Pro 2K 翻倍 |

> 本技能**默认使用标准版**（`qwen-image-3.0`）。仅当用户明确需要 Pro 版的密集排版/极致细节，或主动要求 Pro 时才切换。
